    🏛️ Clase Biblioteca¶

    Gestora principal del catálogo de libros. Implementa operaciones CRUD, búsquedas múltiples, filtros y estadísticas usando contenedores STL y smart pointers.

    📋 Definición¶

    class Biblioteca {
private:
    std::vector<std::shared_ptr<Libro>> catalogo;

public:
    // Gestión básica
    void agregarLibro(const std::shared_ptr<Libro>& libro);
    void mostrarCatalogo() const;
    bool prestarLibro(const std::string& titulo);
    bool devolverLibro(const std::string& titulo);

    // Búsquedas
    std::shared_ptr<Libro> buscarPorTitulo(const std::string& titulo) const;
    std::vector<std::shared_ptr<Libro>> buscarPorAutor(const std::string& autor) const;
    std::shared_ptr<Libro> buscarPorISBN(const std::string& isbn) const;
    std::vector<std::shared_ptr<Libro>> buscarPorCategoria(const std::string& categoria) const;

    // Filtros
    void mostrarDisponibles() const;
    void mostrarPrestados() const;

    // Estadísticas
    int contarLibros() const;
    int contarDisponibles() const;

    // Mantenimiento
    bool eliminarLibro(const std::string& titulo);
};

    🧱 Atributo Privado¶

    Atributo Tipo Descripción
    catalogo std::vector<std::shared_ptr<Libro>> Colección dinámica de libros con ownership compartido

    ¿Por qué shared_ptr?

    • Ownership compartido: El mismo libro puede ser referenciado desde múltiples lugares (catálogo, resultados de búsqueda, UI)
    • Gestión automática: Memoria liberada cuando el último shared_ptr es destruido (RAII)
    • Thread-safe: Contador de referencias atómico (para futuras extensiones concurrentes)

    🔧 Métodos - Gestión Básica¶

    agregarLibro¶

    void agregarLibro(const std::shared_ptr<Libro>& libro);
    Añade un libro al final del catálogo.

    Parámetros: - libro: Referencia constante a shared_ptr<Libro> (evita copia innecesaria del puntero inteligente)

    Ejemplo: 

    Biblioteca biblio;
biblio.agregarLibro(std::make_shared<Libro>("Nuevo libro", "Autor", "ISBN-123", 2024, "Novela"));
// Output: 📘 'Nuevo libro' agregado al catálogo.

    mostrarCatalogo¶

    void mostrarCatalogo() const;
    Imprime catálogo completo formateado con estado de cada libro.

    Ejemplo: 

    --- CATÁLOGO DE LA BIBLIOTECA ---
- 1984 por George Orwell (ISBN: 978-0451524935) [1949] {Ciencia Ficción} (✅ Disponible)
- El Principito por Antoine de Saint-Exupéry (ISBN: 978-0156012195) [1943] {Infantil} (❌ Prestado)
---------------------------------

    prestarLibro¶

    bool prestarLibro(const std::string& titulo);
    Marca un libro como prestado (disponible = false).

    Retorna: true si éxito, false si no existe o ya prestado.

    Estados: | Situación | Retorna | Mensaje | |-----------|---------|---------| | Disponible → Prestado | true | 👍 Has prestado con éxito: ... | | Ya prestado | false | ⚠️ El libro '...' ya está prestado. | | No existe | false | ❌ El libro '...' no existe en el catálogo. |

    devolverLibro¶

    bool devolverLibro(const std::string& titulo);
    Marca un libro como devuelto (disponible = true).

    Retorna: true si éxito, false si no estaba prestado o no existe.

    Novedad v2.0: Retorna bool (antes void) para manejo de errores programático.

    🔍 Métodos - Búsquedas¶

    buscarPorTitulo¶

    std::shared_ptr<Libro> buscarPorTitulo(const std::string& titulo) const;
    Búsqueda exacta por título. Retorna shared_ptr o nullptr.

    if (auto libro = biblio.buscarPorTitulo("1984")) {
    std::cout << "Autor: " << libro->autor << "\n";
} else {
    std::cout << "No encontrado\n";
}

    buscarPorAutor¶

    std::vector<std::shared_ptr<Libro>> buscarPorAutor(const std::string& autor) const;
    Retorna todos los libros de un autor (puede haber múltiples).

    auto libros = biblio.buscarPorAutor("Asimov");
for (const auto& l : libros) {
    std::cout << l->titulo << " (" << l->anioPublicacion << ")\n";
}

    buscarPorISBN¶

    std::shared_ptr<Libro> buscarPorISBN(const std::string& isbn) const;
    Búsqueda por ISBN (identificador único). O(1) lógico, O(n) real (búsqueda lineal).

    auto libro = biblio.buscarPorISBN("978-0451524935");
if (libro) std::cout << "Encontrado: " << libro->titulo << "\n";

    buscarPorCategoria¶

    std::vector<std::shared_ptr<Libro>> buscarPorCategoria(const std::string& categoria) const;
    Filtra por género/categoría. Retorna vector con coincidencias.

    auto scifi = biblio.buscarPorCategoria("Ciencia Ficción");
// Foundation, Dune, 1984, etc.

    📊 Métodos - Filtros y Estadísticas¶

    mostrarDisponibles / mostrarPrestados¶

    void mostrarDisponibles() const;
void mostrarPrestados() const;
    Vistas filtradas por estado. Útiles para UI de usuario.

    contarLibros¶

    int contarLibros() const;
    Retorna catalogo.size() casteado a int.

    contarDisponibles¶

    int contarDisponibles() const;
    Cuenta libros con disponible == true (O(n)).

    int total = biblio.contarLibros();
int libres = biblio.contarDisponibles();
int prestados = total - libres;  // Calculado, no almacenado

    🗑️ Método - Mantenimiento¶

    eliminarLibro¶

    bool eliminarLibro(const std::string& titulo);
    Patrón Erase-Remove Idiom (estándar C++ para filtrar vectores):

    auto it = std::remove_if(catalogo.begin(), catalogo.end(),
    [&titulo](const auto& libro) { return libro->titulo == titulo; });

if (it != catalogo.end()) {
    catalogo.erase(it, catalogo.end());  // Libera shared_ptrs → decrementa ref_count
    return true;
}
return false;

    Eliminación permanente

    Esta operación borra definitivamente el libro del catálogo. Los shared_ptr en resultados de búsquedas previas mantendrían el objeto vivo hasta su destrucción.

    💡 Ejemplos Completos¶

    Flujo típico de préstamo¶

    Biblioteca biblio;
// ... agregar libros ...

std::string titulo = "1984";

// 1. Verificar disponibilidad
if (auto libro = biblio.buscarPorTitulo(titulo)) {
    if (libro->disponible) {
        // 2. Prestar
        if (biblio.prestarLibro(titulo)) {
            std::cout << "Préstamo registrado\n";
        }
    } else {
        std::cout << "Ya prestado\n";
    }
}

// 3. Devolver
biblio.devolverLibro(titulo);

    Búsqueda combinada¶

    // Buscar novelas de 1960s disponibles
auto novelas = biblio.buscarPorCategoria("Novela");
for (const auto& l : novelas) {
    if (l->disponible && l->anioPublicacion >= 1960 && l->anioPublicacion < 1970) {
        std::cout << l->titulo << " (" << l->anioPublicacion << ")\n";
    }
}

    Estadísticas en tiempo real¶

    void imprimirReporte(const Biblioteca& b) {
    std::cout << "=== REPORTE BIBLIOTECA ===\n";
    std::cout << "Total: " << b.contarLibros() << "\n";
    std::cout << "Disponibles: " << b.contarDisponibles() << "\n";
    std::cout << "Prestados: " << (b.contarLibros() - b.contarDisponibles()) << "\n";
    std::cout << "Ocupación: " 
              << (100.0 * (b.contarLibros() - b.contarDisponibles()) / b.contarLibros()) 
              << "%\n";
}

    ⚡ Complejidad Temporal¶

    Operación Complejidad Notas
    agregarLibro O(1) amortizado push_back en vector
    mostrarCatalogo O(n) Recorrido completo
    prestarLibro / devolverLibro O(n) Búsqueda lineal
    buscarPorTitulo / buscarPorISBN O(n) Búsqueda lineal
    buscarPorAutor / buscarPorCategoria O(n) Recorrido + filtro
    eliminarLibro O(n) Erase-remove idiom
    contarLibros O(1) size()
    contarDisponibles O(n) Recorrido con contador

    Optimización futura

    Para catálogos grandes (>10k libros), considerar std::unordered_map<std::string, shared_ptr<Libro>> indexado por ISBN/título para búsquedas O(1).
