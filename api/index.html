    📚 API Reference¶

    Referencia rápida de todos los métodos públicos de las clases principales.

    📖 Clase Libro¶

    Constructor¶

    Libro(std::string t, std::string a, std::string i = "", int anio = 0, std::string cat = "");
    | Parámetro | Tipo | Default | Descripción | |-----------|------|---------|-------------| | t | std::string | - | Título (requerido) | | a | std::string | - | Autor (requerido) | | i | std::string | "" | ISBN | | anio | int | 0 | Año publicación | | cat | std::string | "" | Categoría |

    Atributos Públicos¶

    std::string titulo;           // Título del libro
std::string autor;            // Autor del libro
std::string isbn;             // ISBN-13
int anioPublicacion;          // Año de publicación
std::string categoria;        // Género/categoría
bool disponible;              // true = en biblioteca, false = prestado

    🏛️ Clase Biblioteca¶

    Gestión Básica¶

    agregarLibro¶

    void agregarLibro(const std::shared_ptr<Libro>& libro);
    Añade libro al catálogo.

    Parámetro Tipo Descripción
    libro const std::shared_ptr<Libro>& Puntero inteligente al libro

    Complejidad: O(1) amortizado
    Excepciones: std::bad_alloc si no hay memoria

    mostrarCatalogo¶

    void mostrarCatalogo() const;
    Imprime catálogo completo en stdout.

    Complejidad: O(n)
    Thread-safety: Solo lectura (const)

    prestarLibro¶

    bool prestarLibro(const std::string& titulo);
    Marca libro como prestado.

    Parámetro Tipo Descripción
    titulo const std::string& Título exacto del libro
    Retorno Significado
    true Préstamo exitoso
    false No existe o ya prestado

    Complejidad: O(n) - búsqueda lineal

    devolverLibro¶

    bool devolverLibro(const std::string& titulo);
    Marca libro como devuelto/disponible.

    Parámetro Tipo Descripción
    titulo const std::string& Título exacto del libro
    Retorno Significado
    true Devolución exitosa
    false No estaba prestado o no existe

    Complejidad: O(n) - búsqueda lineal

    Búsquedas¶

    buscarPorTitulo¶

    std::shared_ptr<Libro> buscarPorTitulo(const std::string& titulo) const;
    Búsqueda exacta por título.

    Retorno Significado
    shared_ptr<Libro> Libro encontrado
    nullptr No encontrado

    buscarPorAutor¶

    std::vector<std::shared_ptr<Libro>> buscarPorAutor(const std::string& autor) const;
    Busca todos los libros de un autor.

    Retorno Descripción
    vector<shared_ptr<Libro>> Lista de coincidencias (puede estar vacía)

    buscarPorISBN¶

    std::shared_ptr<Libro> buscarPorISBN(const std::string& isbn) const;
    Búsqueda por ISBN (identificador único).

    Retorno Significado
    shared_ptr<Libro> Libro encontrado
    nullptr No encontrado

    buscarPorCategoria¶

    std::vector<std::shared_ptr<Libro>> buscarPorCategoria(const std::string& categoria) const;
    Filtra por género/categoría.

    Retorno Descripción
    vector<shared_ptr<Libro>> Libros de esa categoría

    void mostrarPrestados() const;

    | Retorno | Total de libros en catálogo |

    int contarDisponibles() const;
    | Retorno | Libros con disponible == true |

    Mantenimiento¶

    eliminarLibro¶

    bool eliminarLibro(const std::string& titulo);
    Elimina permanentemente del catálogo.

    Retorno Significado
    true Eliminado correctamente
    false No encontrado

    Patrón: Erase-Remove Idiom
    Complejidad: O(n)

    🔧 Tipos Comunes¶

    std::shared_ptr<Libro>¶

    Puntero inteligente con ownership compartido.

    // Creación
auto ptr = std::make_shared<Libro>("Título", "Autor");

// Copia (incrementa ref_count)
auto copia = ptr;

// Acceso a miembros
ptr->titulo;
ptr->disponible = false;

// Verificar validez
if (ptr) { /* válido */ }
if (!ptr) { /* nullptr */ }

    std::vector<std::shared_ptr<Libro>>¶

    Vector de punteros inteligentes.

    std::vector<std::shared_ptr<Libro>> libros;

// Iteración
for (const auto& libro : libros) {
    std::cout << libro->titulo << "\n";
}

// Filtrado con algoritmo
auto it = std::remove_if(libros.begin(), libros.end(),
    [](const auto& l) { return l->disponible; });
libros.erase(it, libros.end());

    ⚡ Códigos de Retorno Comunes¶

    Función Éxito Fallo
    prestarLibro true false
    devolverLibro true false
    eliminarLibro true false
    buscarPorTitulo shared_ptr nullptr
    buscarPorISBN shared_ptr nullptr

    📝 Notas de Uso¶

    Const-Correctness¶

    Todos los métodos de solo lectura marcan const: 

    void mostrarCatalogo() const;           // ✅ No modifica estado
std::shared_ptr<Libro> buscar(...) const; // ✅ Solo lectura

    Parámetros por Referencia¶

    Strings y smart pointers se pasan por const&: 

    void agregarLibro(const std::shared_ptr<Libro>& libro);  // ✅ Sin copia
bool prestarLibro(const std::string& titulo);            // ✅ Sin copia

    Move Semantics¶

    Constructor de Libro usa std::move para strings: 

    Libro(std::string t, ...) : titulo(std::move(t)) {}  // ✅ Transferencia O(1)
